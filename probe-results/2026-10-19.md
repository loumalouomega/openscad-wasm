## Live findings (Node 26, `openscad-wasm@0.0.4` as reference)

1. **Correctness:** `.scad` → `.csg` byte-identical to the binary-path oracle
   (`openscad 2021.01`, `cwd=source dir`, `-o` by extension) on all four
   fixtures: `minimal` (339 B), `parametric` (171 B), `include-main` + staged
   `include-lib` (56 B), `colour-booleans` (1270 B). `--backend=manifold`
   accepted; `-D width=60` as separate argv entries works.
2. **Single-use instances:** the FIRST `callMain` render per instance returns
   rc 0; the SECOND render on the same instance throws a bare `Number`
   (e.g. `1124712`) — a C++ exception pointer escaping to JS. This is the
   5th abort vocabulary (`/^\d+$/`) and forces `renderToCsg()` to instantiate
   fresh per call until our own build proves otherwise. Init cost ~150 ms.
3. **Abort shape:** infinite-recursion model throws bare `Number` `1190104`
   at ms 0 (instant, no hang under plain Node — the kernel watchdog question
   stays open for the worker integration).
4. **Stdout purity:** default `print` goes to `console.log` (fd 1) — our
   wrapper defaults both handlers to `console.error`.
5. **print capture:** Emscripten bakes `print`/`printErr` at instantiation;
   post-hoc rebinding has no effect — collection callbacks must be passed to
   the factory (done in `src/openscad.mjs` via `collect`).

## Build (this repo)

- `scripts/build-deps.sh`: native port of DSchroer `Dockerfile.base`
  (zlib → libexpat/libffi → glib → freetype → libxml2 → fontconfig →
  harfbuzz → eigen → double-conversion → libzip → boost 1.87), installing
  into the emsdk sysroot. Skips cgal/gmp/mpfr (Manifold-only first),
  lib3mf + cairo (optional in upstream CMake).
- `scripts/build-wasm.sh`: `WASM_BUILD_TYPE=node-module`
  (`ENVIRONMENT=node,worker`, `EXPORT_ES6`, `MODULARIZE`), `-DENABLE_CGAL=OFF`,
  upstream CI flags (`-DSNAPSHOT=ON -DEXPERIMENTAL=ON`).
- Deps status: zlib, libexpat, libffi done; glib compiling. (2026-10-19 ~22:00 UTC)
