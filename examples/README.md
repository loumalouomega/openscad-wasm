# Examples

Build first (`npm run build`) or put the CI `openscad-wasm-dist` artifact in `dist/`.

- `node/render.mjs` — `node examples/node/render.mjs`: Customizer parameters, STL export, summary, mesh.
- `browser/index.html` — `npm run example:browser`, then open <http://127.0.0.1:8080/examples/browser/index.html>.

See the [examples guide](https://loumalouomega.github.io/openscad-wasm/guide/examples).
