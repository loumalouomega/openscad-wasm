# API reference

Generated by hand from `src/openscad.d.ts`.

## Functions

### `renderToCsg(scadText, options?)`

One-shot `.scad` → `.csg` on a fresh instance. Returns `Promise<string>`; rejects with [`ScadWasmError`](#scadwasmerror).

| Option | Type | Default | |
| --- | --- | --- | --- |
| `defines` | `Record<string, string \| number>` | `{}` | `-D name=value` overrides |
| `backend` | `'manifold' \| 'cgal'` | `'manifold'` | `--backend` |
| `extraFiles` | `Record<string, string>` | `{}` | MEMFS path → contents |
| `wasmBinary` | `Uint8Array` | shipped | wasm bytes |
| `wasmPath` | `string` | shipped | wasm file path |

### `initOpenSCAD(options?)`

Instantiates the module → `Promise<OpenSCADInstance>`.

| Option | Type | |
| --- | --- | --- |
| `collect` | `string[]` | push stdout/stderr lines here (overrides `print`/`printErr`) |
| `print`, `printErr` | `(...args) => void` | default: `console.error` |
| `wasmBinary`, `wasmPath` | | as above |
| `noInitialRun` | `boolean` | forced `true` |

### `evaluateScad(instance, { files, args, outPath })`

Stages `files`, runs `callMain(args)`, reads `outPath`, cleans up. Returns `Promise<{ rc, output, stderr }>`. (`stderr` is always `[]`; capture with `initOpenSCAD({ collect })`.)

### `isOpenScadWasmAbort(message)`

`boolean` — see [Errors & aborts](/guide/errors).

### `getWasmBinary(wasmPath?)`

Reads the shipped `openscad-core.wasm` (cached) or the given path → `Buffer`.
